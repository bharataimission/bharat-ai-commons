# Indian-Language AI Dataset Directory

This directory catalogues existing datasets and data resources relevant to AI for Indian languages and contexts.

**Purpose:** Help researchers, developers, students, and language communities discover resources, understand their intended use, and verify access and licensing requirements.

Bharat AI Commons does not claim ownership of the resources listed here. Each resource remains subject to its own terms, attribution requirements, and access restrictions.

## Important Notes

- This is an initial discovery list, not a comprehensive catalogue.
- Inclusion does not mean that Bharat AI Mission has independently audited or endorsed a resource.
- Access, licensing, and available languages can change.
- Do not assume every dataset linked by a platform has the same license.
- Do not download, redistribute, or modify a dataset until its applicable terms have been checked.
- Dataset quality, representativeness, consent, provenance, and known limitations should be documented where the information is available.

## How to Contribute

Help improve this directory by:

1. Suggesting additional credible Indian-language AI datasets.
2. Verifying official links and current access conditions.
3. Recording dataset-specific licenses and attribution requirements.
4. Identifying language, task, or modality coverage.
5. Improving descriptions and documenting known limitations.

When suggesting a resource, include its official source, supported languages, intended tasks, access requirements, license information, and relevant documentation.

See the repository's contribution guidelines before submitting changes.
