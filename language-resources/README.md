# Indian Language Resources

## Purpose

Bharat AI Commons aims to improve the discoverability, documentation, and understanding of resources needed to build and evaluate AI systems for India's diverse languages.

This directory focuses on language-specific needs, resource gaps, and opportunities for collaboration across research institutions, universities, developers, and open-source communities.

## Areas of Focus

### 1. Language Coverage

Document the availability of AI resources for individual Indian languages, including:

- Text and language corpora
- Speech and audio resources
- Translation resources
- Dictionaries and linguistic tools
- Evaluation datasets and benchmarks

### 2. Resource Gaps

Identify languages and tasks where publicly documented resources appear limited, difficult to access, insufficiently evaluated, or subject to restrictive usage conditions.

Any identified gap should be supported by a documented review rather than assumed from a lack of search results.

### 3. Language and Script Documentation

Capture relevant information about scripts, spelling variations, transliteration, dialects, and other linguistic characteristics that may affect AI development and evaluation.

### 4. Community and Research Collaboration

Encourage collaboration with universities, language researchers, native speakers, educators, and open-source communities to improve resource quality and coverage.

### 5. Indian Context and Cultural Relevance

Explore how language resources can help AI systems better handle Indian names, locations, cultural references, local terminology, and context-specific use cases.

## Suggested Language Resource Record

Where applicable, document:

| Field | Description |
|---|---|
| Language name | Language represented by the resource |
| ISO language code | Standardised language identifier, where available |
| Resource type | Text, speech, translation, dictionary, benchmark, or tool |
| Resource name | Official resource title |
| Source | Official website, repository, or publication |
| Coverage | Task, domain, script, dialect, or data characteristics |
| Licence | Published licence and usage restrictions |
| Documentation status | Reviewed, needs verification, or incomplete |
| Known gaps | Documented limitations or missing information |
| Last reviewed | Date of the most recent review |

## Working Principles

- Do not assume all Indian languages have equivalent resource availability.
- Distinguish language-level evidence from broader multilingual claims.
- Verify resource provenance, licences, and usage restrictions.
- Respect linguistic communities, cultural context, privacy, and consent.
- Clearly distinguish verified findings from preliminary observations.

## Current Status

This directory establishes the initial scope for documenting language resources and research opportunities.

It is not yet a comprehensive inventory of Indian languages or a validated assessment of resource availability.

The initial priority is to identify useful sources, document known resources, and develop a transparent process for identifying gaps.

## Future Work

- Develop a language-resource inventory.
- Map documented datasets and models to supported languages.
- Identify potential research and evaluation priorities.
- Invite universities and language communities to review resource coverage.
- Publish evidence-based observations about gaps and opportunities.
