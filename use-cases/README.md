# Bharat AI Commons — Use-Case Repository

## Purpose

The Bharat AI Commons Use-Case Repository documents how Open Source AI can address real-world problems in India and beyond.

It welcomes proposed ideas, research projects, prototypes, validated solutions and production implementations. Every entry should clearly communicate its evidence, maturity, limitations and potential for reuse.

## Our principles

- **India-first:** Prioritise India's needs, languages, communities and development priorities.
- **Open and collaborative:** Encourage contributions from citizens, students, researchers, developers, institutions, startups and industry.
- **Evidence-aware:** Distinguish proposed ideas from demonstrated and deployed solutions.
- **Reuse-oriented:** Link use cases to relevant datasets, models, benchmarks, tools and source code wherever available.
- **Responsible AI:** Document relevant privacy, safety, bias, licensing and societal considerations.
- **Accessible contribution:** Make it possible to submit an idea without writing code.

## Evidence and maturity labels

Every published entry should use an appropriate maturity label:

- **Proposed idea** — a problem and potential AI approach have been described.
- **Research** — supporting research or experimental evidence is available.
- **Prototype** — an initial implementation or proof of concept exists.
- **Validated solution** — testing or evaluation supports specific claims.
- **Production deployment** — evidence indicates the solution is being used operationally.

Labels must reflect available evidence, not contributor claims alone. Missing evidence should be identified transparently.

## How to contribute

Contributors can propose a problem, document an existing use case, add supporting research or improve a solution's documentation.

The intended workflow is:

1. Submit a use case through an accessible contribution form.
2. Provide source links and available supporting evidence.
3. Allow maintainers to review the submission.
4. Publish accepted entries in the repository and discovery dashboard.
5. Improve entries collaboratively as new evidence becomes available.

## Repository development

This repository will progressively introduce:

- A searchable use-case catalogue
- A standard use-case record template
- Sector-specific organisation
- A submission and review workflow
- Links to reusable datasets, models, benchmarks and code
- Documentation for responsible and reproducible adoption
